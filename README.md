Devices and Configuration

Router3 – Connects Subnet A and the interconnecting Subnet C.
Router2 – Connects Subnet B and Subnet C for inter-network communication.
Switches – Provide wired connectivity within each subnet.
Access Point – Provides wireless access for laptops in Subnet B.
Servers – Each subnet has its own server to simulate local services.

Routing

Static routes are configured to ensure communication between:
Subnet A ↔ Subnet B
Subnet A ↔ Subnet C ↔ Subnet B
This setup allows devices in both LANs to share resources (e.g., servers and applications) through the router connections.
